# PrintEasy — طباعة سريعة

## التشغيل
1. `flutter create --org com.printeasy --project-name printeasy .`
2. انسخ ملفات هذا المجلد فوقه (`pubspec.yaml`, `lib/`, `android/app/build.gradle`, `android/app/src/main/AndroidManifest.xml`).
3. `flutter pub get` ثم `flutter run`.

## الميزات
اتصال (Classic/BLE/USB) • محرك ESC/POS مع العربية كصورة • قوالب نصية • محرر مرئي •
فاتورة سريعة • طباعة جماعية (CSV/Excel) • الطباعة من المشاركة • سجل • إعدادات
