# PrintEasy — طباعة سريعة

تطبيق Flutter لأندرويد لإرسال الصور والمستندات إلى الطابعات الحرارية عبر Bluetooth.

## استقبال الملفات

يمكن فتح شاشة الطباعة من زر **طباعة ملفات** داخل التطبيق، أو مشاركة الملفات إلى PrintEasy من التطبيقات الأخرى. شاشة الملفات تسمح باختيار أكثر من ملف في المرة الواحدة، ومراجعة العناصر قبل إرسالها للطابعة.

## صيغ التحويل الحالية

| الصيغة | المعالجة الحالية |
|---|---|
| JPG / JPEG / PNG / WEBP | إرسال الصورة إلى محرك الطباعة الحرارية |
| PDF | تحويل كل صفحة إلى صورة PNG مستقلة بعرض الورق المحدد |
| CSV | قراءة الصفوف والأعمدة وترتيبها في صفحات صور |
| XLSX | قراءة أوراق المصنف، وتحويل كل ورقة إلى صفحات صور |
| TXT | تحويل النص إلى صفحات صور مع دعم اتجاه العربية |
| HTML / HTM | استخراج النص والفواصل الأساسية ثم تحويله إلى صفحات صور |
| DOCX | استخراج فقرات النص بالترتيب وتحويلها إلى صفحات صور |
| PPTX | استخراج نص الشرائح بالترتيب وتحويله إلى صفحات صور |

**ملاحظات على التوافق:**
- ملفات DOCX وPPTX في النسخة الحالية تُطبع كنص مستخرج؛ لا يتم الحفاظ بالكامل على تصميم Word أو تخطيط الشرائح أو الصور والجداول والخطوط.
- ملفات Excel تُعرض كسطور بيانات مفصولة، ولا يُعاد إنشاء تنسيق الخلايا والألوان والرسوم البيانية.
- HTML تتم معالجة النص والفواصل الأساسية فقط، وليس تخطيط CSS أو الصور.
- صيغ Office القديمة DOC وXLS وPPT غير مدعومة في محولات هذه المرحلة.
- يجب اختبار المستندات العربية والملفات الكبيرة على أجهزة فعلية قبل اعتماد دعمها النهائي.

## عرض الطباعة

تستخدم محولات الصور عرض النقاط المحدد من إعدادات الورق. إعدادات 58mm و80mm مرتبطة بتعريف الطابعة؛ يجب التأكد من العرض الفعلي للطابعة قبل الطباعة لتجنب القص.

## التحقق والبناء

شغّل الأوامر التالية من بيئة Flutter:

- `flutter pub get`
- `flutter analyze`
- `flutter test`
- `flutter build apk --release`

نجاح أوامر البناء لا يثبت وحده جودة الطباعة؛ يلزم اختبار فعلي عبر Bluetooth على الطابعة المستهدفة، بما في ذلك ملفات PDF متعددة الصفحات والعربية والملفات الكبيرة.
